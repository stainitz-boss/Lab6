# Домашнее задание к работе 6: Определение принадлежности точки области

## Условие задачи

> Определите, принадлежит ли точка с координатами \((x, y)\) заштрихованной области между двумя концентрическими окружностями.
> Границы области:
> 1. \(x^2 + y^2 = 1\)
> 2. \(x^2 + y^2 = 9\)

## 1. Алгоритм

1. **Начало**
2. **Ввод координат** точки `x` и `y`.
3. **Вычисление** значения \(R = x^2 + y^2\).
4. **Проверка условия принадлежности:**
   - Если \(R \ge 1\) **И** \(R \le 9\), то точка попадает в заштрихованную область (включая границы).
   - Иначе точка находится вне области.
5. **Вывод** результата.
6. **Конец**

## 2. Контрольные примеры

Для проверки работы программы выберите три точки и заполните пропуски:

1. \((x, y) = (2, 0)\) → принадлежит области (так как \(1 \le 4 \le 9\))
2. \((x, y) = (0, 0)\) → не принадлежит области (так как \(0 < 1\))
3. \((x, y) = (1, 0)\) → находится на границе области (так как \(1^2 + 0^2 = 1\))

## 3. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <locale.h>
#include <stdio.h>

int main()
{
    setlocale(LC_ALL, "RUS");
    float x, y;
    float r_squared;

    printf("Введите координату x: ");
    scanf("%f", &x);
    printf("Введите координату y: ");
    scanf("%f", &y);

    r_squared = x * x + y * y;

    if (r_squared >= 1 && r_squared <= 9)
    {
        printf("Точка (%.2f, %.2f) принадлежит области.\n", x, y);
        
        if (r_squared == 1 || r_squared == 9)
        {
             printf("(Точка находится на границе области)\n");
        }
    }
    else
    {
        printf("Точка (%.2f, %.2f) не принадлежит области.\n", x, y);
    }

    return 0;
}
```

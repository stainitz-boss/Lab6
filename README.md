# Домашнее задание к работе 6: Проверка наличия цифры 5 в числе

## Условие задачи

Дано число **N** (N < 1000). Написать программу, которая проверяет, входит ли в него цифра **5**.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. **Ввод числа** `N` (N < 1000)
3. **Инициализация флага:** `flag = 0` (изначально считаем, что цифры 5 нет)
4. **Проверка сотен:**
   - Если `N >= 100` и `N / 100 == 5`, то `flag = 1`
5. **Проверка десятков:**
   - Если `(N / 10) % 10 == 5`, то `flag = 1`
6. **Проверка единиц:**
   - Если `N % 10 == 5`, то `flag = 1`
7. **Проверка диапазона:**
   - Если `N < 1000`:
     - Если `flag == 1` → вывести «Цифра 5 входит в число»
     - Иначе → вывести «Цифра 5 не входит в число»
   - Иначе → вывести «Неизвестное число N»
8. **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <locale.h>
#include <stdio.h>

int main()
{
    setlocale(LC_ALL, "RUS");
    int N;
    int flag = 0; // есть 5 или нет, по умолчанию нет

    printf("Введите число N (N < 1000): ");
    scanf("%d", &N);

    if (N >= 100) // сотни
    {
        if (N / 100 == 5)
        {
            flag = 1;
        }
    }

    if ((N / 10) % 10 == 5) // десятки
    {
        flag = 1;
    }

    if (N % 10 == 5) // единицы
    {
        flag = 1;
    }

    if (N < 1000)
    {
        if (flag == 1)
        {
            printf("Цифра 5 входит в число N = %d\n", N);
        }
        else
        {
            printf("Цифра 5 не входит в число N = %d\n", N);
        }
    }
    else
    {
        printf("Неизвестное число N\n");
    }

    return 0;
}
```
